# CV App

A modern Curriculum Vitae (CV) builder application built with React and Vite. This app allows users to create, edit, and manage their professional CV with an intuitive form-based interface.

## Features

- **Personal Details Management** - Add and edit your name, email, and phone number
- **Form-based Interface** - Easy-to-use form for entering CV information
- **Edit/Submit Workflow** - Toggle between editing and viewing your information
- **Fast Development** - Built with Vite for rapid development and Hot Module Replacement (HMR)

## Tech Stack

- **React** - UI framework
- **Vite** - Build tool and dev server
- **ESLint** - Code linting and quality

## Getting Started

### Prerequisites

- Node.js (v16+)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

Create a production build:
```bash
npm run build
```

### Preview

Preview the production build:
```bash
npm run preview
```

### Linting

Run ESLint to check code quality:
```bash
npm run lint
```
